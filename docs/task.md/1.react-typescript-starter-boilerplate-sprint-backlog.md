## 🚨 Common Issues & Solutions

### Issue 1: ESLint Flat Config Not Working

**Solution:** Ensure you're using `eslint.config.mjs` (not `.eslintrc.js`) and ESLint 9+.

### Issue 2: Tailwind Classes Not Applying

**Solution:**

1. Verify `tailwind.config.js` content paths include your files
2. Ensure `src/index.css` has `@tailwind` directives
3. Check `src/main.tsx` imports `./index.css`

### Issue 3: Path Aliases Not Working

**Solution:**

1. Update `tsconfig.json` with `baseUrl` and `paths`
2. Update `vite.config.ts` with resolve.alias
3. Restart TypeScript server in IDE

### Issue 4: shadcn/ui Components Not Found

**Solution:**

1. Run `npx shadcn@latest init` first
2. Verify `components.json` exists
3. Install components: `npx shadcn@latest add <component>`

### Issue 5: Husky Hooks Not Running

**Solution:**

1. Run `yarn husky install`
2. Ensure `.husky` directory has executable permissions
3. Check `prepare` script in package.json

### Issue 6: Vitest Tests Failing

**Solution:**

1. Ensure `vitest.config.ts` has correct environment (jsdom)
2. Check test setup file is imported
3. Verify @testing-library packages are installed
