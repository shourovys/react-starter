# Home Feature Module

This feature module contains the home page and related components.

## Structure

- `pages/` - Home page component and tests
- `components/` - Home-specific components
- `hooks/` - Home-specific hooks
- `services/` - Home-specific services
- `store/` - Home-specific state management
- `types/` - Home-specific types
- `utils/` - Home-specific utilities
- `__tests__/` - Feature integration tests

## Usage

````typescript
import { HomePage } from '@/features/home';```
````
