# About Feature Module

This feature module contains the about page and related components.

## Structure

- `pages/` - About page component and tests
- `components/` - About-specific components
- `hooks/` - About-specific hooks
- `services/` - About-specific services
- `store/` - About-specific state management
- `types/` - About-specific types
- `utils/` - About-specific utilities
- `__tests__/` - Feature integration tests

## Usage

```typescript
import { AboutPage } from '@/features/about';
```
